# 🐍 Curso de Python - SENAC

Repositório criado para armazenar exercícios, atividades, projetos e anotações desenvolvidos durante o curso de Python no SENAC.

## 📖 Sobre

Este repositório tem como objetivo documentar minha jornada de aprendizado em Python, registrando a evolução dos conhecimentos adquiridos ao longo das aulas e práticas propostas no curso.

## 🚀 Tecnologias Utilizadas

* Python 3
* Visual Studio Code
* Git
* GitHub

## 📂 Conteúdo

Ao longo do curso, este repositório poderá conter:

* Exercícios de lógica de programação
* Estruturas condicionais e de repetição
* Funções
* Manipulação de listas, tuplas e dicionários
* Programação Orientada a Objetos (POO)
* Manipulação de arquivos
* Pequenos projetos práticos
* Anotações de aula

## 💻 Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/victorhugorochadasilva021-droid/python-senac.git
```

2. Entre na pasta do projeto:

```bash
cd python-senac
```

3. Execute o arquivo desejado:

```bash
python nome_do_arquivo.py
```
